# Harness实践：金融监管Agent稳定运行

> 原文：InfoQ AICon 深圳 2026-08-08，演讲者：于浩军（中软融鑫总工程师）

## 背景
Agent 落地的关键瓶颈已从模型能力转向系统工程能力，尤其在金融监管等高可靠性场景中，数据与知识资产质量及持续增强的工程体系决定 Agent 稳定性。

## 核心观点
- 金融监管场景要求零容错、强追溯、口径复杂，Agent 实际运行高度依赖结构化知识库与可验证数据链。
- Harness 工程方法论聚焦模型之外的智能体稳定性保障，强调知识与数据双向驱动。
- 实践验证：Agent 在监管报表全链路（采集→计算→检核→复核→血缘追溯）中，稳定性取决于工程化治理而非模型调优。

## 演讲者
于浩军，中软融鑫总工程师，曾参与原中国银监会 1104 工程建设、人民银行金融基础数据体系建设等。近年来聚焦“金融监管 × AI Agent”融合方向。

## 应用场景：Agent 在金融监管中要解决什么
- 核心挑战：口径复杂、频度高、零容错、强追溯；通用 Agent 的三大痛点为口径漂移、幻觉、不可解释。
- 需求侧：解析监管要求 + 比对内部数据情况，自动生成采集逻辑、处理程序、质量控制规则。
- 报送中：智能数据初始化、自动质量检核。
- 问题处置：根因分析、血缘分析、数据追溯、缺失数据智能补全。
- 报送前：数据复核、生成复核报告、给出审核建议。

## Harness 体系解决方案
### AIR Harness：面向金融监管的智能体底座
- 核心能力：Agent / Skill / Tools / MCP 创建，服务于“口径受控、数据可查、逻辑可溯”。
- 口径受控执行：Agent 依据已治理的知识/数据资产执行，高频场景固化为标准 Skill。
- 受控连接：MCP 对接明细/指标/报表库、监管知识库、勾稽血缘图库，取数与知识引用可审计。
- 全链路可追溯：记录每一步调用，报送结果可逐层回溯到规则与数据源。

### 双知识底座
- 向量知识库：存储监管制度/口径说明/数据字典，MCP 接入增强 RAG。
- 图数据库：存储指标勾稽、数据血缘、报送逻辑关系，解决“口径依赖上下文、指标依赖计算逻辑”。

### 数据资产管理
- 数据分层：明细类、指标类、报表类、非结构化。
- 三类定义入库为知识：表/字段定义、指标口径与计算逻辑、报表口径频度范围。
- Agent → 治理提效：自动完善元数据、识别数据标准、安全分级分类、数据确权。
- 数据资产 → Agent 反哺：自动生成取数 SQL、取指标方法、数据知识问答。

### 数据质量管理闭环
- 以数据资产为基础的动态监测。
- Agent 自动生成检核规则、评估有效性。
- 问题闭环：根因/血缘/追溯 → 处置流程 → 考核评价。
- 自动生成质量分析报告、考核评价报告。

## 经验与展望
- 双向驱动飞轮：治理越好 → Agent 越稳 → 治理更高效。
- 痛点：数据资产和知识资产在初步形成及后续维护过程中的质量稳定性及稳定性评价方面，还存在不可控因素。
