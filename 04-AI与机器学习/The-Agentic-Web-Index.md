# The Agentic Web Index

互联网正从主要面向人类构建的环境，快速演变为被机器大量使用的环境。AI 代理、爬虫、数据抓取工具等机器人正在重塑信息发现、访问和使用方式。该指数基于 5,000+ 网站的 Agent Analytics 和 AI Chat Referral Tracking 数据，提供关键生态指标。

## 关键指标

- **Bot vs. Human Traffic**：35%（较前 90 天下降 1%），机器人访问量占比。
- **Agentrification**：29%（较前 90 天上升 11%），机器人流量中与 AI 相关的比例。
- **AI Chat Referral Volume**：0.1%（较前 90 天下降 9%），人类网站访问中来自 AI 聊天的比例。
- **Robots.txt Effectiveness**：98.5%，机器人遵守 robots.txt 规则的比例。
