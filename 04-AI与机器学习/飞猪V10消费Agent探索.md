## 补充：飞猪 V10 消费 Agent 探索（InfoQ）

**日期**：2026-08-07  
**来源**：InfoQ 中文站（原题：从回答问题到把事办完，消费 Agent 还缺什么？飞猪新一代 AI 产品 V10 的一次探索）

### 核心观点
- 飞猪 CTO 陈烨指出，AI 产业价值仍过度集中于基础模型与算力层，消费场景 Agent 尚未形成稳定 PMF。
- 信息检索与 Coding 已率先找到 PMF，但消费 Agent 难以处理实时供给、交易和履约的复杂闭环。
- 价值需要向编排层与应用层迁移；Coding 的 PMF 路径不可简单复用于强履约场景。

### V10 产品能力
- “帮我想”：解析旅行笔记，生成行程规划。
- “帮我订”：覆盖复杂筛选需求（如迪士尼前门、宠物友好、适合老人）。
- “帮我办”：交易后履约服务（值机、选座、升房、开发票、退款、关联订单）。
- AI Panel 从独立页面进入搜索、交易、订单等具体场景。

### 架构与工程实践
- 从 Multi-Agent + Workflow 转向 ReAct AgentLoop，原则是“架构上做减法，模型层面做加法”。
- 采用“受约束的自主性”：商品白名单、短别名、数据沙箱、时空规则、在线轻验证。
- 模型工具返回的商品映射为 A1/A2 短别名，推理完成后回填真实 ID，避免字符生成错误。
- Agent 能力建设三阶段：Prompt（命令式改声明式）、机制、训练（后训练，Reward Model 覆盖信息真实性、用户需求与偏好、时空合理性、结果完整性与多样性）。

### LUI 与 GUI 关系
- 保留 GUI 在浏览、比较和交易方面的效率；LUI 处理精准、复杂和长尾需求。
- LUI 可作为 GUI 的自然语言入口；“想、订、办”是用户教育与能力指引，未来可能合并。

### 评测方法
- 关注结果“可用率”，先确定评测标准、筛选评测集，机器多模型投票 + 人工抽样复核。
- 评测是为了决定什么结果可以交给用户，不是为了刷榜。
