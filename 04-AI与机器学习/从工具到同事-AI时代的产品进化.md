# 从“工具”到“同事”——AI 时代的产品进化

> 苏杰在 QCon 2026 北京站的演讲实录。他以 AI 数字分身完成主体演讲，实证 AI 正重构产品创新范式与人类角色边界。核心观点：AI 不再是工具，而是平等协作的“新同事”；产品、技术、设计边界消融，催生“全栈 builder”；下一代人机交互趋于极简——语音键 + accept/reject/enter 四键足矣。

## 大判断：产品、组织、个人的若干暴论

- **互联网折叠空间，AI 折叠时间**：互联网解决共时性问题（人、数据、设备连接）；AI 将人类历史智慧压缩进模型，并能推导未来可能性，属于历时性。AI 算力会解构所有建立在人类认知局限之上的东西——方法论、学科壁垒、岗位边界。
- **AI 解构有损压缩**：方法论（SWOT、波特五力）都是人类认知带宽不足时的“套路”。AI 可一事一议、case by case 解决问题。人的独特价值在于：提出问题、评判结果、承担责任。
- **未来没有 to B 产品，只有 to C 和 to A**：to B 产品本质是给人类包一层 GUI 去读写数据库。Agent 不需要 GUI，直接调 API 即可。流程化执行工作交给 agent（to A），重要决策留给人（to C）。商业模式从按坐席收费转为按用量微支付。
- **A to A 直连**：企业内部数据流转不再需要人类可读界面，agent 之间直接对接。人退到少数重要决策位置，像高级管理者，不干活但拍板。
- **Save time vs Kill time**：save time 产品（办公工具、效率软件）用户将从人类变为 AI，最终管道化、to A；kill time 产品（游戏、社交、内容、线下体验）依赖感官交互浓度，线下永远大于线上，是真正触达人类的产品。
- **三个方向**：向左死磕技术边界（内核，如 DeepSeek），向右直面市场风险（外壳，如 Manus），更底层的是硬件入口——人必须通过硬件与软件交互，手机厂、车厂、robot 厂机会大于 app 厂。

## 新形态：轻产品 · 现炒型 · 生成系统

- **软件从“预制菜”变“现炒”**：过去开发在前、使用在后，固态长生命周期，代码是资产；AI 时代即用即做，液态、用完即走，prompt + data 是资产。
- **轻产品**：可交互的内容；天然开源（用户可用自然语言二创）；次抛性；生命周期是脉冲（涌现、爆发、湮灭）而非 S 曲线。
- **生成系统才是真正的产品**：产品是水流，生成系统是水龙头；真正值钱的是水龙头。产品经理不再直接设计产品，而是设计产品生成系统（定义参数、设定约束、注入价值观）。2.0 版 PM 甚至为自己定制工具，人人都是产品经理。
- **GitHub 可能是下一代应用商店**：Agent 不关心图标和 UI，只看成本、效率、效果。GitHub 天然是代码 + 文档 + 接口的集合，碳基与硅基兼兼容，成为 agent friendly 的分发渠道。
