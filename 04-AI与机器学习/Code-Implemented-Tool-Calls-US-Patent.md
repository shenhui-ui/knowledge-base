# Mistral AI 专利：代码实现的工具调用（US 12,670,045 B1）

## 摘要

该专利由 Mistral AI 申请，发明人 Gabriel Vergnaud，公开号 US 12,670,045 B1，申请日 2026-03-04。核心是一种让 LLM 通过生成代码块来封装和执行工具调用的方法，在沙箱中运行代码，遇到外部工具调用时暂停，交由客户端执行后再恢复。

## 核心流程

1. 服务器接收用户请求，要求执行一个或多个工具调用。
2. LLM 生成编程语言代码块，代码块封装这些工具调用。
3. 服务器在沙箱中执行该代码块。
4. 当遇到 pending tool call（挂起工具调用）时，暂停代码执行。
5. 将挂起的工具调用传输给客户端执行。
6. 接收客户端返回的第一结果。
7. 恢复代码执行，并将第一结果替换代码块中的 pending tool call。
8. 将代码块执行的第二结果返回给 LLM。

## 意义

这种设计将工具调用的执行从服务端解耦到客户端，允许在不暴露沙箱内部状态的情况下，让客户端介入执行具体的工具调用（如访问本地资源或私有 API）。对 Agent 系统的架构设计有参考价值。

## 权利要求要点

- 方法包含服务器接收、LLM 生成代码块、沙箱执行、暂停、转发客户端、接收结果、恢复、返回。
- 共 20 项权利要求，分类号 G06F 9/547（应用程序接口调用）。
