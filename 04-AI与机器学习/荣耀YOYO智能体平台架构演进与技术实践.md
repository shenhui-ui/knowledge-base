# 荣耀YOYO智能体平台架构演进与技术实践

> 摘要：荣耀 YOYO 智能体平台采用“端-脑-服”三位一体架构，聚焦跨端协同、多模态感知、主动服务与隐私安全，并针对 Node 发现、上下文一致性、任务 Replan 等工程挑战给出实践路径。

## 背景：Agent 竞争转向系统化工程能力

模型能力逐渐成为行业共识后，真正的竞争力转向围绕模型构建可规模化的智能系统，从单点能力提升转向系统工程与组织级落地能力。消费级 Agent 的关键变量包括跨设备协同、任务闭环和隐私安全。

在 2026 年 AICon 人工智能开发与应用大会·深圳站上，荣耀 AI 平台部架构师聂鹏鹤分享了 YOYO 智能体平台的架构演进与实践，主题为《从 App 容器到 Agent 调度中心：荣耀YOYO智能体平台的架构演进与技术实践》。

## YOYO 智能体架构

### “端-脑-服”三位一体

- **端（感知）**：多模态感知、数据不出端，深度耦合终端硬件能力。
- **脑（调度）**：全局上下文构建、意图路由与任务 Replan。
- **服（执行）**：跨端数据协同、生态共创，闭环用户的任务执行。

## 核心实践：跨端协同与生态共创

- 跨端数据协同方案：打破设备孤岛，构建全局上下文。
- 场景案例：YOYO 助理如何闭环用户要执行的任务。

## 五大核心能力

1. **多模态感知**：看懂/听懂/感知，结合端侧硬件实现实时理解。
2. **个性化学习推理**：基于端侧数据越用越懂你。
3. **主动服务**：服务找人，而不只是人找服务。
4. **隐私安全**：数据不出端，安全嵌入智能体全生命周期。
5. **类自动驾驶意图执行**：复杂任务自动拆解，自主闭环。

## 工程实践中的关键挑战

- **Node 的识别与发现**：跨设备能力节点发现存在实践痛点。
- **跨端任务上下文一致性**：多设备间上下文需保持一致，是消费级 Agent 的核心难点。
- **任务 Replan**：任务执行过程中的重规划环节仍存在实践难点。

## 演讲提纲（四部分）

1. **智能体——AI 时代的“新桥梁”**：架构总览：“端（感知）- 脑（调度）- 服（执行）”三位一体模型。
2. **核心实践：跨端协同与生态共创**：跨端数据协同方案；场景案例。
3. **工程实践——五大核心能力**：多模态感知、个性化学习推理、主动服务、隐私安全、类自动驾驶意图执行。
4. **未来展望与生态开放**：消费级 Agent 的下一个进化方向；开放 YOYO 智能体平台，支持第三方开发者接入。

## 未来展望与生态开放

- 消费级 Agent 的进化方向：从单点应用到跨场景的主动式智能体。
- 开放 YOYO 智能体平台，支持第三方开发者接入，构建“自研打底 + 行业共创”的生态。

## 听众收益

- **架构视野**：深入理解荣耀 AI 智能体“端-脑-服”三位一体的系统级架构设计思路。
- **生态洞察**：了解荣耀如何通过“自研打底 + 行业共创”构建开放智能体生态的策略。
- **技术前瞻**：多模态感知、意图路由、隐私安全等 AI Agent 核心技术的发展趋势与落地路径。

## 演讲人

聂鹏鹤，荣耀 AI 平台部架构师，10+ 年企业数智化经验，聚焦多端感知、跨端协同与智能体交互，致力于通过智能体实现“意图驱动服务”的下一代交互体验重构。
