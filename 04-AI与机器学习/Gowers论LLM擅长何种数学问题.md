# Gowers论LLM擅长何种数学问题

> 本文来自 Gowers's Weblog，讨论了 OpenAI 宣布解决多个重大数学/理论计算机问题后，LLM 在数学上的当前能力边界，尤其关注“LLM 是否特别擅长找反例”这一假设。

## 背景

- 作者写作时（2026年8月初）距 OpenAI 宣布解决十个重大数学与理论计算机问题仅几天。
- 其中包括：非 sofic 群的首次构造；多色 Ramsey 数（3色）超指数增长的证明。
- 作者认为这些结果令人印象深刻，但 LLM 尚未在所有数学方面超越所有人类——否则它们巨大的速度优势应带来更多结果洪流。

## 核心问题

LLM 擅长解决哪类问题？是否特别擅长**找反例**？

- 作者指出，LLM 不仅擅长找反例，也能给出困难陈述的证明。
- 但最著名的问题大多以**反例**而非证明形式解决（如 Jacobian 猜想、单位距离猜想）。

## “反例”含义的辨析

要论证“LLM 特别擅长找反例”，需先明确什么算反例。

以 Vinogradov 三素数定理为例：

> 每个足够大的正整数都是三个素数之和。

其否定形式等价于：每个正整数都有一个性质 P（即存在某个 N 使得……）。若按形式化定义，Vinogradov 定理也可被描述为“找到一个不具备 P 的整数”——但显然应归类为**定理证明**而非“找反例”。

因此，不能简单地说 LLM 擅长否定全称量化命题；问题取决于全称量化的**本质**以及第一个“有趣”的量词变量。

## 意义

作者自知尚未给出清晰的分类学答案，但试图排除一些显然错误的解释，并关注尚未被证据否定的潜在答案。这篇反思记录了 2026 年 LLM 数学能力发展初期的一手观察。
