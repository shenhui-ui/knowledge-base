# Oracle禁止AI生成代码进入OpenJDK

Oracle 已禁止 OpenJDK 贡献中使用 AI 生成的代码，理由是安全、知识产权风险。开发者仍可在私有环境中使用 LLM 进行调试和代码审查，但不得将 AI 生成的内容提交到仓库、Pull Request 或其他项目渠道。

这一政策与 Oracle 内部做法形成鲜明对比：创始人 Larry Ellison 声称 AI 模型已开始编写 Oracle 的代码，联合 CEO Mike Sicilia 也称赞 AI 工具让更小的工程团队实现更快交付。

与此同时，Oracle 正以每年 700 亿美元规模扩张数据中心，信用评级机构 S&P 因此将其评级下调至 BBB-（仅比垃圾级高一档），理由是投资回报不确定。

## 要点

- OpenJDK 禁止提交 AI 生成代码，但允许使用 LLM 辅助调试与审查
- Oracle 内部却宣称广泛使用 AI 编程，公开政策与内部实践矛盾
- 巨额数据中心投资引发信用评级下调，反映 AI 基础设施投入的财务风险
