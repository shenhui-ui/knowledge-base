# Snowflake Cortex Agents 本体驱动推理实践

> 本文介绍了 Snowflake Cortex Agents 如何通过引入本体（Ontology）与知识图谱、GraphRAG 技术，增强 AI 智能体对企业业务概念的理解与推理能力。

## 背景：关系数据与领域语义的鸿沟

企业数据往往以表、列、键和连接的形式存储，但其中隐含的领域知识（如分类层级、同义词、约束）并未被显式建模。许多行业维护着正式本体（OWL/RDF/SKOS），如：

- 医疗：SNOMED CT、UMLS、Gene Ontology、Cell Ontology
- 供应链：GS1
- 金融：FIBO

然而，大多数 AI 系统仍主要运行在关系抽象之上，无法原生访问概念继承、传递关系、等价映射或领域约束的知识层，导致“组织对真实世界含义的建模方式”与“AI 系统检索和推理业务数据的方式”之间存在鸿沟。

## 生物医学基准测试

Snowflake 团队构建了一个生物医学数据集来验证本体感知方案的增量价值：

- **Cell Ontology (CL)**：33,651 个术语，由约 50,000 条层级边和关系边连接
- **PRISM 数据集**：4,518 种药物 × 578 个人类癌细胞系，共 260 万余条细胞存活率测量数据

难点在于 PRISM 按组织类型（如肺、乳腺）标注，而 Cell Ontology 按细胞谱系（如上皮细胞、基质细胞）组织概念，智能体必须跨越语义鸿沟才能回答分析问题。

团队设计了 22 个高难度问题，每种配置重复运行 5 次，评估术语解析、队列比较、跨组织分析、药物排序、分布分析和多类别比较等能力。

## 方案一：基线 Semantic View + Cortex Analyst

基线方案使用 Snowflake Semantic View 构建受治理的语义层，将药物、蛋白质靶点、细胞系等表示为逻辑实体，再用事实记录可测量事件，用维度提供分析上下文，用指标编码派生度量。Cortex Analyst 将自然语言转换为针对该语义层、经过验证的 SQL。

该方案作为对照基准，用于衡量在语义模型之上叠加本体感知技术后带来的增量提升。

## 方案二：知识图谱遍历

在 Semantic View 之上，使用 Snowflake 表实现简单的知识图谱，支持更自然的图遍历操作。

### 存储模型

- `KG_NODE` 表：存储所有实体，包括唯一标识符、类型和属性（属性保存在 VARIANT 列中）
- `KG_EDGE` 表：存储关系，包括源节点 ID、目标节点 ID、边类型（如 treats、targets、expressed_in）及可选元数据

这种实现充分利用 Snowflake 的分布式存储、自动扩展、查询优化与安全治理能力，无需引入独立图数据库。

### 递归 CTE

递归公共表表达式（Recursive CTE）允许动态、可变长度的图遍历。例如从“药物 → targets → 蛋白质 → triggers → 通路 → expressed in → 细胞类型 → affected in → 疾病”的推理链中动态扩展，无需预先知道路径深度。

### 可用工具

智能体可访问 7 个工具，例如：

- `expand cohort`：扩展队列
- `get ancestors`：获取祖先节点
- `get hierarchy path`：获取层级路径
- `get cohort efficacy`：获取队列药效

示例 `get_ancestors` 输入 `squamous epithelial cell`，沿 `subClassOf` 向上遍历，返回上皮细胞（depth 1）、真核细胞（depth 2）、细胞（depth 3）等祖先节点。

优势是可在支持的层级深度内进行确定性遍历，例如将“epithelial cell”扩展至全部 693 个后代概念；局限是 7 个工具带来编排复杂性，存储过程要求精确概念名，不具备同义词解析能力。

## 方案三：扁平化 GraphRAG

GraphRAG 不在查询时遍历图，而是预先为每个概念计算一份反规范化画像，包含概念名称、定义、同义词、局部邻域，以及从后代概念聚合得到的属性，再将这些画像索引到 Cortex Search 中，支持关键词与向量的混合检索。

运行时，智能体检索最相关的概念画像，从中提取有明确知识依据的业务或科学上下文，再传递给 Cortex Analyst 或下游 SQL 生成环节。

该模式检索架构更简单，通过更强的同义词处理提升一致性，且运行时不需图遍历；但系统质量高度依赖扁平化画像的构建质量与更新机制。

## 结论

在评估条件下，更充分的结构化知识锚定有望提升准确性与可靠性。本体感知的增强方案在基准测试中展现出更高的准确性和可解释性，结构化知识锚定能够弥补关系型数据与领域语义之间的建模鸿沟，为构建更精准、可解释、可信的企业级 AI 智能体提供了一套可落地的参考框架。
