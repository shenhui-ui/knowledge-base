# 幽灵字符：JIS汉字编码中的未解之谜

1978年，日本通产省制定了后来被称为 JIS X 0208 的编码标准，该标准至今仍是所有日语编码的重要参考。然而标准发布后，人们注意到其中几个新增字符没有明确来源，无人能解释其含义或读音。这些字符被称为“幽灵字符”（幽霊文字）。

## 调查经过

很长时间里，幽灵字符只是被遗忘的奇闻。1997年，一项调查启动，试图找出它们的来源。JIS 标准中的字符本应记录出处，但即使有出处也很模糊，通常只列出来源文档。幽灵字符常见的来源之一是《国土行政区画総覧》，一部收录日本地名的综合性作品。这不是几百页的地图集，而是七卷本、每卷约900页的巨著，在没有页码的情况下查找单个字符极为困难。

调查访问了参与标准制定的编目员，确认部分字符是编目过程中的偶然错误。例如：

- **妛**：原本要记录“山在女上”的合字，因无法打印为一个字符，便将“山”和“女”分开打印、剪下粘贴到纸上再复制。复制时，两张纸片接缝的线条被误认为笔画，加入了字符。真正的原字（𡚴）直到很久以后才加入 JIS 和 Unicode。

## 核心幽灵字符

```
妛挧暃椦槞蟐袮閠駲墸壥彁
```

最终，只有一个字符既无明确来源也无历史先例：**彁**。最可能的解释是它是误读“彊”而产生的，但未发现具体事件。

## 影响与传承

JIS 标准被广泛采用后，这些字符进入 Unicode，而 Unicode 在 CJK 统一过程中又引入了自己的一套幽灵字符。1978年一系列小错误凭空创造了几个字符，错误未被及时发现，最终被固化。如今这些“幽灵”潜藏在全球每台计算机的字符表角落，可能将永远伴随人类文明。
