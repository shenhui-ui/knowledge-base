# .NET MAUI 11 Preview 6 架构更新

微软发布 .NET 11 Preview 6，包含多项 .NET MAUI 架构改进，核心是转向 Handler 架构，淘汰 Xamarin.Forms 时代 renderer。

**主要更新：**

- **CollectionView2 登陆 Windows**：新的 Windows handler 使用 WinUI ItemsRepeater，与 Android/iOS/Mac Catalyst 的 CV2 实现对齐，支持虚拟化、分组、选择、页眉页脚、空视图、吸附、增量加载和 RefreshView。
- **Android Shell 迁移到 Handler**：新增 ShellHandler、ShellItemHandler、ShellSectionHandler，替代 renderer 类，iOS/Mac Catalyst 仍用旧实现。
- **HybridWebView 互操作改用源生成器**：消除裁剪和 AOT 警告，支持完全裁剪和 Native AOT；Android 上过滤来自嵌套框架的无关 postMessage 事件。
- **Geolocation 改进**：GeolocationListeningRequest 新增 MinimumDistance 属性，按距离触发位置通知。
- **MediaPicker 恢复支持**：Android 上可在进程被终止后获取、等待或清除媒体选择结果。
- **移除 Compatibility 包**：`Microsoft.Maui.Controls.Compatibility` 被移除，依赖 Xamarin.Forms 兼容 renderer 的项目必须迁移。
- **其他修复**：CollectionView、Shell、Material 3 样式、iOS 26、XAML 生成、无障碍等；Apple 工作负载面向 Xcode 26.6；.NET for Android HTTP 行为调整。

开发者可在微软 Preview 6 公告中找到安装说明，并在官方 GitHub 发布说明中查看详细的 MAUI 变化、关联 issue 和平台说明。.NET 11 Preview 6 已作为预览版运行时和工具包提供下载。
