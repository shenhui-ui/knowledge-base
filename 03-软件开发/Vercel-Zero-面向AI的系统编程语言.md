# Vercel 发布新语言 Zero：代码不是写给人看的，而是写给 AI 的

Vercel Labs 发布了实验性系统编程语言 **Zero**，其设计基于这样一个前提：编译器输出的主要阅读者不再是人类，而是 AI 智能体。Vercel 的 Chris Tate 于 2026 年 5 月 15 日发布这门语言，定位为“速度更快、体积更小，而且更便于智能体使用和修复”的系统语言。项目已推进至 v0.3.4，GitHub 上获得超过 5200 个 Star。

## 核心特性

- **体积与速度**：Hello World 程序可在一毫秒内构建，大小仅 16.2 KiB。
- **工具链契约**：单一 `zero` 二进制文件的每个子命令都支持统一的 `--json` 标志，使用相同诊断模式；错误携带 `NAM003` 等稳定代码，以及 `declare-missing-symbol` 等带类型的修复元数据。`zero fix --plan --json` 返回机器可读的修复计划，智能体可接受、编辑或拒绝。
- **显式副作用**：任何与外部世界交互的函数必须接受一个 `World` 能力参数，由编译器强制执行。仅看函数签名即可判断代码是否能访问网络、文件系统或标准输出。

## v0.3.0 的重大变更

v0.3.0 将图优先创作设为常规工作流：

- 二进制 `zero.graph` 存储作为编译器输入，`.0` 文件变为供人类阅读的投影。
- 智能体通过 `zero query` 和 `zero patch` 工作，补丁受图哈希保护，过期或无效的编辑会在写入存储前失败。
- 编译器拒绝源码投影输入，现有文本优先软件包需使用 `zero import` 导入源码到图中，并通过 `zero export` 和 `zero verify-projection` 进行人工审查及 CI 漂移检查。
- v0.3.2 将大型程序的 `zero import` 速度提升约 12 倍。

## 语言定位与争议

Zero 使用 `.0` 文件扩展名，Apache 2.0 许可证，可编译为 Linux、macOS 和 Windows 原生二进制。与成熟语言相比，Zero 在二进制体积和显式分配上更接近 Zig 而非 Rust，缺乏 Rust 借用检查器的成熟度和生态系统，并以 Go 的绿色线程和较大运行时为代价换取了体积小巧且不依赖外部组件的构建产物。

Hacker News 上的评论存在分歧：有人认为能力机制是唯一新东西且解释不足，结构化错误早已存在；也有人反驳称重点在于智能体而非开发者。还有用户质疑“智能体最擅长的语言将是预训练数据中出现最多的语言”，但 Svelte 等项目的重大 API 变更表明训练数据的重要性可能低于预期。

## 状态

Zero 是 Vercel Labs 的开源项目，仍处于实验阶段，预计会有破坏性变更，应在隔离的工作区中运行，不适用于生产系统或敏感数据处理。
