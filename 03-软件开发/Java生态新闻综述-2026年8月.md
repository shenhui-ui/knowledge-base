# Java生态新闻综述（2026年8月）

本文编译自 InfoQ 的 Java 新闻综述，涵盖 OpenJDK、JDK 版本更新、Jakarta EE、GraalVM、TornadoVM、Micronaut、Quarkus、JobRunr、Maven 等近期重要动态。

## OpenJDK 动态

- **JEP 539（JVM 严格字段初始化预览版）** 从 Proposed to Target 提升至 Targeted，计划在 JDK 28 交付。该 JEP 引入严格初始化字段，读取前必须初始化，避免看到默认值（如 0、null），可供生成 class 字节码的编译器直接使用。
- **JEP 401（值对象预览版）** 同样提升至 Targeted，计划在 JDK 28 交付。值对象仅包含 final 字段、无标识符、仅通过字段值区分。
- **JEP 535（Shenandoah 默认启用分代模式）** 从候选提升至 Proposed to Target，计划在 JDK 28 交付。非分代模式将被弃用并计划移除。
- **JEP 542（加密对象 PEM 编码）** 从 Draft 提升至候选阶段。该功能在 JDK 25-27 三轮预览后拟最终确定，支持 PEM 与 PKCS#8、X.509 格式互转，并将 PEM 记录类改为普通类，`DEREncodable` 更名为 `BinaryEncodable`。

## JDK 版本更新

- **JDK 27** 早期访问构建 Build 33 发布，修复了各种问题。
- **JDK 28** 早期访问构建 Build 9 发布，修复了各种问题。

## Jakarta EE

- **Jakarta Agentic AI 1.0.0-M1** 发布，引入新的内部 TCK 基础设施，覆盖真实行为语义；新增 `@RequiresEngine` 和 `@RequiresNoEngine` 注解，用于替代 JUnit 的 `@Disabled`。
- **Eclipse Starter for Jakarta EE** 更新，支持 Jakarta EE 11，运行时包括 Azul Payara、GlassFish、Open Liberty。

## GraalVM 25.2

主要变更：
- 全新的 Graal Script Agent（早期预览 Java 库），可将自然语言请求转换为沙箱化的应用程序插件。
- 全平台（含 Windows）支持 Native Image 上的 G1 GC。
- 默认启用 Java Vector API。

## TornadoVM GPULlama3 1.0.0

基于 TornadoVM 的开源 GPU 加速 Llama 3 推理项目正式发布，新增功能：
- 支持 CUDA 后端，利用 Tensor Core MMA 实现批量预填充硬件加速。
- 新增兼容 OpenAI 的 HTTP API 服务器。
- 新增 `RunMetrics` 类改进性能指标收集。

## Micronaut 5.1.0

主要更新：
- 新增 `@Property` 注解（嵌套在 `@Introspected` 中），支持有序集合注入。
- CDI 集成钩子。
- 支持通过 Kotlin Symbolic Processing API 遍历 Kotlin 内部类。
- 支持 OpenDI（Eclipse 兼容的 CDI Lite 实现）。

## Quarkus 3.38.0

- 支持基于权重的内存驱逐（针对 Caffeine/JCache 的 Second Level Cache 区域）。
- 新增 HTTP Problem 扩展，实现 RFC-7807，标准化 problem+json 响应。

## JobRunr 8.8.0

- 改进 `BackgroundJobServer` 遇到 `StorageException` 时的日志记录。
- 支持 Kotlin 2.4。
- Quarkus 用户使用 SmallRye Health 时不再需要额外依赖。

## JDKUpdater 26.0.33+211

帮助开发者跟踪 OpenJDK 与 GraalVM 构建更新的工具，适应近期 OpenJDK 关键补丁更新节奏的变化。

## Maven 4.0.0 RC6

- 支持将 Java 模块名称作为附加 artifactId，方便多模块项目生成多个工件。
- 将 maven-executor 依赖提取为独立项目。
- 注意存在已知兼容性问题及更严格的 POM 验证要求。
