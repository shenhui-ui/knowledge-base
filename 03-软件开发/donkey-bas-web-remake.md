# DONKEY.BAS 网页重制版

DONKEY.BAS 是早期 IBM PC DOS 自带的演示程序，展示了 BASICA 的彩色图形与声音能力。它由微软联合创始人比尔·盖茨与 Neil Konzen 于 1981 年编写（1.10 版于 1982 年发布）。游戏玩法简单：玩家只能切换车道，躲避驴子，否则 BOOM。

该网页项目使用 JavaScript 重新实现了原始 CGA 玩法，并加入了声效、CRT 滤镜、作弊模式和全屏支持等现代功能。原始源码可在 GitHub 上获取（DONKEY.BAS）。
