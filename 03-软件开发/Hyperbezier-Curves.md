# The Mathematical Beauty of Hyperbezier Curves

Raph Levien 提出一种新的曲线族，可能取代三次贝塞尔曲线（cubic Bézier）成为 2D 矢量图形设计的基础。该曲线族由 Cesàro 方程定义，指定曲率作为弧长的函数：

$$\kappa(s) = \frac{as+b}{(cs^2+ds+1)^{1.5}}$$

## 与三次贝塞尔的关系

- 在小角度时与三次贝塞尔曲线行为非常相似，逼近精度高。
- 在大角度或控制柄“臂长”较大时，拟合不再紧密，但控制方案仍可用来设置超贝塞尔曲线参数（直接设置多项式系数不直观）。
- 交互式编辑场景下不需要完美映射，可通过调整控制点达到期望形状。

## 包含的精确解析曲线

- **Euler 螺旋**：当 c == d == 0 时取得，具有平滑单调曲率变化，是最小变分曲线问题的解。
- **圆弧**：当 a == 0 时精确取得（三次贝塞尔只能近似圆弧）。
- **对数美学曲线**：参数空间内可达到曲率指数 -3、-2、-1.5、-0.5（对应 α = 1/3, 1/2, 2/3, 2），包括圆内渐开线（circle involute）和 Euler 螺旋的渐屈线（evolute）。

## 超椭圆与方形圆角（Squircles）

- 三次贝塞尔无法逼近尖角，会提前产生额外拐点；超贝塞尔可以一直逼近尖角，视觉上接近超椭圆。
- 对中等指数（如 5），最佳三次贝塞尔拟合精度略高，但超贝塞尔在视觉上行为正确，是一种略有不同的“squircle”。

## 双曲线（Hyperbola）

- 双曲线在转弯处是圆的，曲率逐渐衰减并趋近线性渐近线，三次贝塞尔难以拟合且不表现出渐近行为。
- 超贝塞尔能天然且高精度拟合双曲线，两者渐近曲率均满足 $\kappa \approx s^{-3}$。

该曲线族是替代三次贝塞尔的强有力候选，兼具平滑曲率变化与大张力峰值区域的表现力。

## 补充：控制点映射与曲线性质

- 参数映射原则：控制柄臂长（arm length）设定分母多项式，分子通过端点切线匹配解出；交互编辑中无需完美映射，微调控制点即可达到目标形状。
- 与三次贝塞尔相比，超贝塞尔整体曲率变化更平滑、更易保持单调曲率；小角度下两者行为非常接近。
- 参数映射经过设计：当控制点落在 Euler 螺旋平行曲线的"双抛物线"上时，结果恰为精确 Euler 螺旋。
