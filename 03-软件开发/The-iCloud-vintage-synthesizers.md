# The iCloud vintage synthesizers：浏览器原生复古合成器Patch备份工具

The iCloud vintage synthesizers 是一个面向复古合成器用户的 Web MIDI 工具，目标是在浏览器中直接完成合成器音色 Patch 的备份、整理与搜索。它被 Synthtopia、ModWiggler 等媒体介绍，并被描述为“零配置的 MIDI-OX 替代品”。

## 主要特点

- **100% 浏览器原生**：无需安装驱动，无应用散乱，打开网页即可使用。
- **Web MIDI 硬件连接**：将合成器的 MIDI 端口连接到电脑后，可直接读取 RAM 内存库寄存器中的 Patch 名称。
- **Secure SysEx 数据库**：复古合成器硬件耐用，但内部 RAM 电池会耗尽。该工具可将自定义 Patch 工程备份到私有云库，长期保护数据。
- **搜索与导出**：支持搜索音色库、将 Patch 目录导出为 CSV，并可一键恢复到硬件。
- **已有规模**：80+ 专属 librarian，740 个 Patch 已成功备份。
- **推荐接口**：建议搭配 Roland UM-ONE 或 iConnectivity mio 等高质量 MIDI 接口使用。

该工具展示了 Web MIDI API 在硬件音频设备管理方面的实用场景，对于前端工程师与音乐技术爱好者都有参考价值。
