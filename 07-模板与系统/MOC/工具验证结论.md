# Insight Flow 模板归档能力验证

## 验证方法

抓取以下资料并核对源码中报告输出路径/文件命名机制：

1. 官方文档（中文站，2026-08-08 抓取）：
   - `https://insight-flow.potatodog.cc/zh/introduction`
   - `https://insight-flow.potatodog.cc/zh/quickstart`
   - `https://insight-flow.potatodog.cc/zh/features/destinations`
   - `https://insight-flow.potatodog.cc/zh/features/reports-and-archive`
2. 仓库源码（GitHub `PotatoDog1669/insight-flow` main 分支，通过 `git/trees/main?recursive=1`（717 文件，未截断）定位关键文件后逐一抓取）：
   - `backend/app/sinks/obsidian.py` — Obsidian 落盘核心逻辑
   - `backend/app/renderers/daily.py`、`weekly.py`、`base.py` — 报告标题生成
   - `backend/app/destinations/config.py` — destination 配置规范化
   - `backend/app/template_engine/renderer.py` — 模板引擎（仅渲染内容，不参与路径）
   - `backend/tests/sinks/test_obsidian_sink.py`、`backend/tests/renderers/test_renderer_naming.py` — 命名行为测试
3. `config.yaml`（仓库根目录）

## 证据

### 1. 输出路径是固定目录拼接，无模板变量

`backend/app/sinks/obsidian.py`：

```python
def _build_filename(title: str) -> str:
    return f"{title.replace('/', '-').strip()}.md"   # 文件名 = 标题，无日期格式化 (L118-119)

def _normalize_target_folder(target_folder: str) -> str:
    return target_folder.strip().strip("/")           # 仅去除首尾斜杠 (L122-124)

def _resolve_local_target_dir(*, vault_path: str, target_folder: str) -> Path | None:
    target_dir = Path(vault_path)
    if target_folder:
        target_dir = target_dir / Path(target_folder) # 静态目录拼接 (L137-139)
```

输出目录 = `vault_path / target_folder`（固定字符串），文件名 = 标题 + `.md`。全仓库源码（717 文件树）中未出现 `strftime` / `%Y-%m` / `{yyyy` 等路径模板变量；`target_folder` 不经过任何模板展开。

### 2. 配置项只有静态目录，无日期子目录配置

`config.yaml`（L49-50）：

```yaml
sink:
  obsidian:
    vault_path: ""
```

`backend/app/destinations/config.py`（L25-35）obsidian 默认配置：

```python
"obsidian": {
    ...
    "target_folder": "AI Daily/",   # 纯静态字符串
}
```

### 3. 日期只进入文件名（标题），不进入目录

`backend/app/renderers/daily.py`（L229）：`title=f"AI 早报 {context.date}"`
`backend/app/renderers/weekly.py`（L15）：`title=f"AI 周报 — {context.date}"`

即文件名形如 `AI 早报 2026-08-08.md`，但目录仍是固定 `target_folder`，不会生成 `2026-08/` 子目录。

### 4. 唯一带日期的落盘路径是论文摘要，目录仍为固定名

`backend/app/sinks/obsidian.py`（L62-79）：paper digest 模式输出到固定 `DailyPapers/` 目录，文件名 `f"{report_date}-论文推荐.md"`；paper note 模式输出到固定 `DailyPapers/Papers/` 目录。`report_date` 来自运行 metadata，不改变目录层级。

### 5. 测试佐证路径不含日期

`backend/tests/sinks/test_obsidian_sink.py`（L37-59）：`target_folder: "AI Reports/Daily"` → 期望路径 `vault/AI Reports/Daily/Daily - Brief.md`，无日期目录。

### 6. 文档未承诺日期归档能力

官方文档 `features/destinations.mdx` 仅描述 `vault_path` / `api_url` / `api_key` / `target_folder` 配置与模式选择，未提及日期子目录或路径模板；`features/reports-and-archive.mdx` 的"归档"指数据库内报告列表，非文件系统按月归档。

## 结论

**unsupported** — Insight Flow 报告只输出到固定目录 `vault_path/target_folder/`，文件名由标题派生（daily/weekly 标题含日期故文件名含日期），但**无日期子目录机制、无路径模板变量**（如 `{date:%Y-%m}`），也无法通过配置实现按月归档。

影响：需要观察者脚本（Task 7）实现 `2026-08/2026-08-08.md` 式归档。利好：文件名内嵌日期（如 `AI 早报 2026-08-08.md`、`AI 周报 — 2026-08-08.md`），观察者脚本可直接按文件名解析日期，无需解析文件内容。
