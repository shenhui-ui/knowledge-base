# 知识库使用指南

## 目录规则
- 数字前缀目录（00-99）为固定骨架，**不新增**数字前缀目录
- 新主题归入 03-软件开发 / 04-AI与机器学习 / 05-数据分析 下已有子目录；确需新子目录时在其所属主题区内新建（不带数字前缀）
- 文件名用中文，日期统一 `YYYY-MM-DD`

## 快速捕捉
- 任何临时内容直接丢进 `00-收件箱`，不分类
- 自动管线（每天 08:10）会把收件箱素材消化成 wiki 文章并移入 `99-归档/`；文件名含 `@manual` 的素材由管线跳过（保留人工处理）
- 日记模板顶部会显示收件箱待整理数量

## 资讯日报（只写区域）
- `02-资讯日报/` 由 Insight Flow 工具写入，**只读不手改**；日报按 `YYYY-MM/` 月归档
- 引用日报内容用链接（如 `[[AI 早报 2026-08-08|当日日报]]`），不复制正文；日报文件名以工具实际输出为准（当前前缀「AI 早报」，若工具标题模板变化需同步更新）
- 手动笔记一律进 `00-收件箱`

## 项目规范
- 一个项目一个文件夹：`06-项目/<项目名>/`
- `概述.md` 一次性；`进展.md` 按日期分节滚动追加（不写决策）；`决策记录/` 每条决策一个原子笔记 `YYYY-MM-DD-<主题>.md`（背景/方案/决定/影响）；`复盘.md` 阶段或结束时写
- 用「项目概述模板」新建项目，用「决策记录模板」新建决策（决策记录目录无自动模板绑定，新建时用 Templater 命令面板手动插入「决策记录模板」）

## 模板使用
- 日记：Daily Notes 每日自动用「日记模板」，当日日报链接自动指向当天日期
- 学习笔记：主题区新建笔记时用「学习笔记模板」（领域、来源、摘要、要点、结论/行动）
- MOC：`07-模板与系统/MOC/` 下用「MOC模板」建地图页；每季度检查一次是否需更新

## 回顾机制
- 每周：查看 MOC Dashboard（本周新增笔记），清空收件箱
- 每月：检查 MOC 是否有待整理项
- 附件：新附件默认落 `07-模板与系统/附件/`，按 `YYYY-MM/` 子目录归档整理

## 首次使用与运维
- **打开 vault**：Obsidian 注册可能仍指向旧路径（`专业`），用「打开文件夹」选择本目录 `/home/genrobot/Obsidian`
- **版本要求**：Obsidian 需 ≥ 1.13.0（Templater 插件要求），过低则模板不生效
- **观察者服务**：日报归档由 `obsidian-archive-watcher` systemd 用户服务常驻执行；重启后检查：`systemctl --user status obsidian-archive-watcher`（服务异常时手动启动：`systemctl --user start obsidian-archive-watcher`）
- **健康检查**：每日 22:30 自动检查当天日报是否生成，缺失时记录到 `/tmp/obsidian-check.log`；可手动执行 `python3 /home/genrobot/Obsidian/07-模板与系统/脚本/check_daily_report.py` 验证
- **git 提交注意**：本仓库根在 `/home/genrobot`，存在大量无关未跟踪文件，提交时只 `git add` 指定路径，**禁止 `git add .` / `git add -A`**
