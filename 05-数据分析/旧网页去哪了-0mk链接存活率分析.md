# 旧网页去哪了：657,607个链接的存活率分析

2026年7月，0.mk 团队从旧数据库备份中恢复了一份 2009–2014 年间的链接记录，共 657,958 条。经清洗后，对 657,607 条有效记录（以及 494,781 个去重 URL）进行了大规模存活率爬取，试图回答“旧网页去哪了”。

## 核心结论

- **76.7% 的历史链接已无法加载**：在 655,178 条可爬取链接中，仅 23.32% 返回 2xx/3xx 响应。
- 51.24% 在网络层失败（DNS、超时、TLS），25.44% 返回 HTTP 错误（4xx/5xx）。
- 在去重后的 492,620 个 URL 中，仅 **21.3%** 仍能加载，78.7% 无法访问。
- HTTP 404 是最常见的错误，涉及 76,403 个不同 URL；另有 29,663 个 URL 返回 403/429，可能只是拦截了爬虫。

## 域名层面

在 133,605 个可爬取主机名中，仅 34,827 个（约 26%）有至少一个 URL 能加载，其余 98,778 个完全无法访问。集中式平台（YouTube、Wikipedia、Google）存活率明显高于个人博客、论坛和本地新闻站。

## 年度分布

| 年份 | URL 无法加载占比 | 主机无法加载占比 |
|------|----------------|----------------|
| 2009 | 64.58% | 61.53% |
| 2010 | 60.39% | 60.36% |
| 2011 | 92.53% | 61.74% |
| 2012 | 59.43% | 62.46% |
| 2013 | 75.06% | 75.24% |
| 2014 | 78.16% | 75.45% |

2011 年的 URL 级异常高值由单账户批量创建的 83,398 条指向 pelaphptutorials.com 的链接造成；去除该批次后，2011 年记录从 103,053 降至 19,655，与相邻年份一致。链接数量增长并不等于用户规模增长。

## 墓园漫步

- **Facebook 照片 CDN（fbcdn.net）**：835 条链接指向 789 个不同 URL，全部无法加载。
- **Google Code**：803 条链接，628/754 个 URL 仍可访问或重定向至存档。
- **PureVolume**：796 条链接，633/653 个 URL 仍返回页面（服务已死，域名尚存）。
- **Rapidshare**：139 条链接，无一加载。
- **Megaupload**：71 条链接，无一加载。
- **Picasa Web Albums**：69 条链接，无一加载。

一个 HTTP 响应并不等于原始内容仍在。登录墙、停放域名广告页、“内容已下架”提示都会被计为“加载”，但真正的信息可能早已消失。

## 结语

0.mk 用户主要集中在北马其顿，因此这不是全网普查，而是一个社区六年间分享内容的巨大样本。小网站正在从互联网上消逝，而中心化平台与域名停放服务仍维持着响应——这或许是我们理解数字记忆流失方式的又一佐证。
